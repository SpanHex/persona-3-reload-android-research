# Persona 3 Reload — Ahead-of-Time (AOT) Recompilation Proof of Concept

This directory contains the reproducible, standalone Proof of Concept (POC) demonstrating the **x86-64 &rarr; LLVM IR &rarr; AArch64 Android native recompilation pipeline** for the Persona 3 Reload Android research initiative.

> [!NOTE]
> This is a **RESEARCH PROOF OF CONCEPT ONLY**. It does NOT contain commercial game assets, decrypted PlayStation 4 executables, or copyrighted materials. All tests are conducted using original synthetic C fixtures and open-source compiler toolchains.

---

## 2. Prerequisites & Setup

The toolchain requires Python 3.10+ with the following packages:

```bash
pip install llvmlite capstone keystone-engine lief
```

- **LLVM Backend (`llvmlite` v0.50.0):** Generates LLVM Intermediate Representation and compiles to AArch64 ELF objects.
- **Capstone Disassembler (`capstone` v5.0.9):** Decodes instruction operands and disassembles emitted AArch64 machine code.
- **Keystone Assembler (`keystone-engine` v0.9.2):** Assembles synthetic x86-64 test fixtures into binary blobs.
- **LIEF Library (`lief` v1.0.0):** Parses and validates ELF headers, section tables, and relocations.

## 3. How to Run the Pipeline

### Step 1: Assemble Synthetic Test Fixtures
To assemble all 5 synthetic C fixtures into standalone x86-64 machine code blobs in `tests/bin/`:

```bash
python phase3-poc/tests/scripts/build_fixtures.py
```

### Step 2: Run the AOT Recompiler Driver
To compile an individual fixture to native AArch64 ELF object (`.o`), GNU assembly (`.s`), C dispatch table (`.c`), and JSON statistics:

```bash
# Example: Recompile Fixture 02 with Extra Entries
python phase3-poc/compiler/p3r_recomp.py \
    --input phase3-poc/tests/bin/02_dispatch.bin \
    --base-vaddr 0x402000 \
    --entry 0x402000 \
    --extra-entries phase3-poc/tests/fixtures/02_extra_entries.txt \
    --out-asm phase3-poc/tests/bin/02_dispatch.s \
    --out-obj phase3-poc/tests/bin/02_dispatch.o \
    --out-c phase3-poc/tests/bin/02_dispatch_dispatch.c \
    --stats phase3-poc/tests/bin/02_dispatch_stats.json
```

### Step 3: Run the Automated Validation Harness
To audit the target hardware via ADB, validate all emitted AArch64 ELF objects, verify ABI invariants, and compare against the oracle manifest:

```bash
python phase3-poc/android-runtime/runner.py
```

## 4. Key Architectural Findings

1. **AOT Recompilation is Fast & Feasible:** The pipeline recompiles x86-64 machine code to native AArch64 ELF objects with an expansion factor of only $1.57\times$.
2. **UE4 Requires a Hybrid Execution Model (Option C):** Pure static AOT discovery misses dynamic delegate calls in Unreal Engine 4, requiring an integrated FEXCore JIT fallback to prevent runtime aborts (`BBR_TRAP_MISS`).
3. **Snapdragon 7s Gen 2 Hardware Constraints:** The Realme 12 Pro+ has ample CPU capacity across 4x Cortex-A78 cores, but memory bandwidth is constrained to $17.06\text{ GB/s}$ ($10.3\times$ lower than the PS4's GDDR5 bus). The graphics renderer must target 720p or 540p with AMD FSR 1.0 upscaling.
